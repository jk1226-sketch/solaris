How to make S.O.L.A.R.I.S. work for all public visitors without showing your key

Never paste a raw gsk_... key directly inside public HTML code, because anyone can view page source and steal it. Instead, use a free Cloudflare Worker (takes 2 minutes):

  1. Sign in at dash.cloudflare.com (free) → Workers & Pages → Create Worker.
  2. In Worker Settings → Variables & Secrets, add a secret named GROQ_API_KEY with your gsk_... key.
  3. Paste this 12-line relay into the Worker editor and click Deploy:
export default {
  async fetch(req, env) {
    if (req.method === "OPTIONS") return new Response(null, { headers: { "Access-Control-Allow-Origin": "*", "Access-Control-Allow-Headers": "*" } });
    const body = await req.text();
    const res = await fetch("https://api.groq.com/openai/v1/chat/completions", {
      method: "POST",
      headers: { "Content-Type": "application/json", "Authorization": `Bearer ${env.GROQ_API_KEY}` },
      body
    });
    return new Response(res.body, { headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*" } });
  }
};

4. Copy your https://...workers.dev link into EMBEDDED_WORKER_URL at line 356 of this HTML file—now everyone can use S.O.L.A.R.I.S. instantly!
